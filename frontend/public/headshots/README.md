# Researcher headshots

Place the headshots provided by the client in this folder (JPG or PNG, square,
at least 160x160 px; name each file after the researcher's AUID, e.g. `ABC1234.jpg`),
then map each AUID to its file in `src/config/researcherPhotos.js`.
Files here are served from `/headshots/<file>`. Researchers without a photo show
their initials.
